# Project 1A 中文提示

本项目要求实现基于双向链表的 `LinkedListDeque61B<T>`。`Deque61B` 接口中的方法已按建议的实现顺序排列。

## 接口行为

- `addFirst(x)`：把非 `null` 元素添加到队首。
- `addLast(x)`：把非 `null` 元素添加到队尾。
- `toList()`：返回内容相同的新 `List`，不能修改原双端队列。
- `isEmpty()`：返回队列是否为空，不能修改队列。
- `size()`：返回元素数量，不能修改队列。
- `removeFirst()` / `removeLast()`：删除并返回队首或队尾元素；队列为空时返回 `null`。
- `get(index)`：用迭代方式读取指定索引；越界时返回 `null`，不能修改队列。
- `getRecursive(index)`：用递归方式读取指定索引；越界时返回 `null`，不能修改队列。

## 结构要求

前置条件测试要求 `LinkedListDeque61B`：

- 使用一个类型参数实现泛型；
- 恰好包含一个内部节点类，内部类本身不应再次声明泛型参数，而应使用外部类的泛型；
- 节点恰好包含两个节点引用和一个泛型值字段；
- 整体保持严格的双向链表拓扑；
- 除节点引用和基本类型字段外，不应增加其他状态字段；
- 只提供一个无参数构造方法。
