# Project 1C 中文提示

本项目继续使用 `Deque61B`，并包含最大值双端队列测试与吉他弦模拟。

## Deque 接口

`deque.Deque61B` 的方法行为与 Project 1A、1B 相同：两端添加和删除、转换为 List、判空、获取大小，以及迭代和递归两种索引读取方式。索引越界或从空队列删除时返回 `null`。

## MaxArrayDeque61B

测试会使用构造时提供的 `Comparator<T>` 比较元素，并期望 `max()` 返回比较意义下的最大元素。例如按字符串长度比较时，应返回最长的字符串。

## GuitarString

- 在开始本部分前，需要先完成 `Deque61B` 的实现。
- 缓冲区容量为 `SR / frequency`，转换为整数前使用 `Math.round()` 可获得更高精度；初始缓冲区填满 `0.0`。
- `pluck()` 清空缓冲区，并为每个位置分别调用 `Math.random() - 0.5` 生成白噪声样本。
- `tic()` 执行一次 Karplus–Strong 更新：移除队首样本，将前两个样本平均值乘以 `DECAY` 后加入队尾。不要在此方法中调用 `StdAudio.play()`。
- `sample()` 返回缓冲区队首样本，并且不能改变吉他弦状态。
- 测试允许 `tic()` 计算结果存在 `0.001` 的误差。
