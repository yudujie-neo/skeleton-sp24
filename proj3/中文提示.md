# Project 3A / 3B / 3C 中文提示

当前仓库将 Project 3 的所有阶段放在同一个 `proj3` 目录中，没有独立的 `proj3a`、`proj3b` 或 `proj3c` 骨架。下面按本地代码中的三类任务整理提示。

## 3A：世界生成

- 在 `World` 中设计并生成你自己的世界，使用 `TETile[][]` 表示世界状态。
- 使用统一的伪随机数生成流程，使相同种子可重现相同世界。`RandomUtils` 提供多种随机分布和打乱工具，也允许修改。
- `Tileset` 提供常用图块。鼓励添加自定义图块，但该文件会与项目一起提交。
- 可在 `WorldGenTests.basicTest` 中替换不同种子，渲染世界并停留 5 秒查看结果。

## 3B：交互与统一输入

- `Main` 是程序入口，用于启动世界与交互。
- `AutograderBuddy.getWorldFromInput(input)` 必须在不渲染、不调用 `StdDraw` 的情况下模拟相同的键盘输入，并返回最终世界。
- 字符串输入与真实键盘输入应共用同一套状态转换逻辑，便于测试结果一致。
- 为交互编写自己的测试，例如使用 `"n123swasdwasd"` 检查新游戏和移动序列。

## 3C：保存、载入与自动评测接口

- 输入以 `:q` 结尾时，应保存并退出。在 `getWorldFromInput` 中，退出的含义是保存后直接返回 `TETile[][]`，绝对不能调用 `System.exit(0)`。
- `FileUtils` 提供写文件、读文件和检查文件是否存在的辅助方法，且允许修改。
- 建议测试两段等价输入：先调用 `"n123swasd:q"` 保存，再调用 `"lwasd"` 载入并继续移动。
- 如果添加了新的地面、物品或边界图块，必须同步修改 `isGroundTile` 或 `isBoundaryTile`，使自动评测器能正确分类。

## 渲染器注意事项

`TERenderer` 通常不需要修改。除非需要屏幕滚动、角色跟踪等特殊效果，建议先完成其他功能。如果为 UI 更改了 `StdDraw` 画笔或字体设置，应在继续绘制图块前调用 `resetFont()`。
