## Algorithms

### 命令处理顺序

填写无参数、未知命令、参数错误、未初始化等输入的判定顺序。说明每条命令在哪个阶段读状态、验证失败条件、写工作文件和保存仓库元数据。

### 基础命令

填写 init、add、commit、rm 的核心步骤。重点解释 add 时如何保存内容，commit 如何继承父快照，rm 如何区分暂存取消和追踪移除。不要只重述命令的功能。

### 查询和状态

填写 log 的父链遍历、global-log 的全部对象枚举、find 的匹配和 status 的排序。若实现完整 status，说明三种版本比较的判定。

### 恢复与分支

填写单文件 checkout、分支 checkout 和 reset 如何复用代码。分别说明工作文件、Stage、当前分支名、分支引用的变化。说明阻挡检查如何在任何写入前完成。

### Merge

填写祖先图遍历与最新共同祖先的选择；祖先和 fast-forward 如何处理；单文件状态如何决策；冲突字节如何构造；双亲提交怎样生成；无变化错误怎样处理。

### 时间与空间

填写每个核心操作依赖哪些规模：文件大小、快照文件数、分支数、历史提交数或祖先数。说明完整 ID 与短 ID 的查找区别，以及未改文件内容为何不会重复存储。

### 不变量和失败处理

写出你的不变量，例如：分支引用指向存在的提交；一个文件不会同时暂存增加与移除；已经保存的历史不修改；每个暂存 blob 都能被下次进程找到。说明规范规定的错误发生时怎样避免部分写入。
