# Project 1B 中文提示

本项目要求实现基于数组的 `ArrayDeque61B<T>`。`Deque61B` 接口中的方法已按建议的实现顺序排列，其行为与 Project 1A 相同。

## 接口行为

- 支持在队首和队尾添加元素；输入元素假定不为 `null`。
- `toList()` 返回独立的 List 副本，不能改变原队列。
- `isEmpty()` 和 `size()` 只查询状态，不能改变队列。
- 从空队列调用 `removeFirst()` 或 `removeLast()` 时返回 `null`。
- `get(index)` 使用迭代方式读取，越界时返回 `null`。
- `getRecursive(index)` 使用递归方式读取，越界时返回 `null`。

## 结构要求

`ArrayDeque61BPreconditionTest` 要求实现类的字段只能是：

- 作为底层存储的数组；
- 基本类型字段；
- 编译器生成的合成字段。

不要使用其他集合代替底层数组。测试骨架中的结构测试展示了相同限制。
