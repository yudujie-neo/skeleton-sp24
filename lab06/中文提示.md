# Lab 06 中文提示

本实验要求自行创建 `BSTMap<K, V>`，用二叉搜索树实现 `Map61B<K, V>` 接口。声明中应包含 `implements Map61B<K, V>`。

## 必做方法

- `put(key, value)`：插入键值对；键已存在时替换值，不应增加 `size`。
- `get(key)`：返回键对应的值，键不存在时返回 `null`。
- `containsKey(key)`：只判断键是否存在。即使该键映射到 `null`，也应返回 `true`。
- `size()`：返回不同键的数量。
- `clear()`：清空所有映射并把大小恢复为 0。

`keySet()` 和 `remove(key)` 是可选部分。如果不实现，请抛出 `UnsupportedOperationException`。

## 测试提示

- `TestBSTMap` 的部分测试依赖其他基础方法已正确实现，适合按 `put` / `get` / `containsKey` / `size` / `clear` 的顺序排查。
- `containsKey` 不能通过 `get(key) != null` 简单判断，因为映射值本身可以是 `null`。
- `TestBSTMapExtra` 只覆盖可选的 `keySet` 和 `remove` 功能，其中 `remove` 测试并不穷尽所有树结构。
- `InsertRandomSpeedTest` 会向 `ULLMap`、你的 `BSTMap`、Java `TreeMap` 和 `HashMap` 插入随机字符串，可用于比较运行时间。
